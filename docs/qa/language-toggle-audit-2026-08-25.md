- **P0 — 공통 언어 스위처 통일**: 페이지별 수동 수정보다 공통 `LanguageSwitcher` 컴포넌트로 통일

- **P2 — 28개 페이지 中文 일괄 추가**: KR·EN·JP가 있는 페이지에 중국어 추가
- **P3 — 자동화 테스트**: 모든 slug에서 4개 버튼 존재 → 각 언어 URL 200 → 동일 slug 유지 → 현재 언어 버튼 활성화 여부를 Playwright/Cypress로 검사

## 3. 개발 완료 판정 기준

- 모든 후킹페이지 상단에 KR / EN / JP / 中文가 동일한 순서와 UI로 표시된다.
- 각 버튼 클릭 시 같은 작품 slug의 해당 언어 페이지로 이동한다.
- 현재 선택 언어가 색/밑줄/배경 등 한 규칙으로 시각적으로 구분된다.
- 번역 페이지가 없을 때의 `준비 중` 정책 또는 4개 언어 완성 후 발행 규칙을 정한다.
- 신규 콘텐츠 발행 시 4개국어 버튼 테스트를 배포 체크리스트에 자동 포함한다.
