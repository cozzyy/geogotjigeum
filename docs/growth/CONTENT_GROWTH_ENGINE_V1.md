# 그곳지금 Content Growth Engine v1

## Status
**APPROVED — PLANNING / RESEARCH CAN RUN IN PARALLEL WITH DESIGN CLOSEOUT**

2026-08-28 사용자 승인에 따라, 그곳지금의 다음 성장 단계는 UI 추가보다 **검색 유입을 만들고 들어온 사용자가 장소를 연속 탐색하도록 만드는 콘텐츠 성장 엔진** 구축으로 전환한다.

## 1. 핵심 목표

그곳지금을 단순한 작품별 촬영지 모음이 아니라 다음 흐름을 가진 구조로 키운다.

`검색 → 작품/장면 → 실제 장소 → 지역 → 지도 → 관련 작품/장소 → 재탐색`

장기 구조는 다음 관계를 축적하는 **K-content Location Graph**다.

`작품 ↔ 장면 ↔ 등장인물 ↔ 배우 ↔ 촬영지 ↔ 지역 ↔ 주변장소`

## 4. 전략 원칙

### 원칙 A — 기존 승자부터 밀기
신규 작품 30개를 한꺼번에 만드는 것보다, 이미 7~17위권에 있는 페이지를 먼저 10위 안으로 올린다.

### 원칙 B — 신규 작품은 '화제성 × 장소성'으로 고른다
유명하다는 이유만으로 추가하지 않는다. 실제 촬영지/배경 장소를 검증할 수 있고, 사용자가 여행·장소 탐색으로 이어질 수 있어야 한다.

### 원칙 C — 페이지 하나가 아니라 그래프를 만든다
새 작품 1개를 만들 때 최소 다음 연결을 계획한다.
- 작품 → 핵심 장소
- 장소 → 관련 작품
- 장소 → 지역
- 지역 → 같은 지역 다른 작품/장소
- 작품 → 지도
- 상위 작품은 퀴즈 → 실제 장소 결과

### 원칙 D — 다국어는 선택과 집중
- KR: 전반적인 검색 성장의 기준 언어
- JP: 이미 순위가 보이는 작품/일본 배경·일본 팬덤 우선
- EN: 글로벌 IP와 경쟁이 약한 location/filming-location 롱테일 우선
- 繁中: 준비상태가 검증된 상위 자산부터 확대

### 원칙 E — 검증되지 않은 여행정보를 만들지 않는다
영업시간, 가격, 이동수단, 폐업/운영상태, 실제 촬영 여부 등은 신뢰 가능한 근거가 없으면 쓰지 않는다.

## 5. 성장 우선순위 점수(100)

| 항목 | 배점 | 판단 기준 |
|---|---:|---|
| 검색/팬덤 수요 | 30 | GSC 실적, 프랜차이즈 인지도, 공식 플랫폼 화제성 |
| 최신성/모멘텀 | 20 | 신작·신시즌·재개봉·현재 화제성 |
| 장소성 | 20 | 실제 장소 수, 여행 연결성, 검증 가능성 |
| 글로벌/다국어 잠재력 | 15 | 해외 팬덤, 국가간 검색 수요 |
| 내부링크 확장성 | 10 | 기존 작품·장소·지역과 연결 가능성 |
| 제작 난이도/위험 | 5 | 검증 난이도, 데이터/이미지/저작권 리스크의 역점수 |

실제 GSC 수치가 있는 기존 페이지는 **프록시 점수보다 GSC 데이터를 우선**한다.

## 6. 기존 콘텐츠 등급

### A — NOW / SEO 가속
실제 Search Console에서 이미 1페이지 또는 경계권 증거가 있는 작품. title/meta/H1/H2, 장소 설명, 내부링크, 관련 지역 연결을 먼저 개선한다.

### B — BUILD / 데이터 자산 활용
장소/인물 데이터가 풍부하고 서비스 정체성과 맞지만 아직 GSC 성과 증거가 약한 작품. 내부링크와 콘텐츠 깊이를 보강해 테스트한다.

### C — MAINTAIN / 에버그린
팬덤은 크지만 현재 사이트의 한국여행/장소발견 정체성과 직접 연결이 약하거나 경쟁이 강한 글로벌 IP. 유지하며 글로벌 롱테일을 노린다.

### D — DEFER / 증거 부족
검색수요, 장소성, 검증 데이터가 모두 약한 경우. 삭제가 아니라 투자 보류이며 GSC 신호가 생기면 재평가한다.

## 7. 실행 루프

`후보 수집 → 점수/증거 확인 → Research Brief → 촬영지 검증 → 콘텐츠 기획 → 내부링크 계획 → 언어 우선순위 → GitHub Issue → 구현/생성 → QA → 배포 → GSC 2주/4주 재측정`

### 기존 페이지 개선 루프
1. GSC query/page 확인
2. 검색의도 한 문장 정의
3. title/meta/H1/H2 개선
4. 장소/숨은 이야기 보강
5. 작품→장소→지역→지도 내부링크 보강
6. 모바일 가독성/CTA 확인
7. IndexNow/sitemap 정상 여부 확인
8. 14일 후 순위/CTR 비교

### 신규 작품 루프
1. 화제성 후보 등록
2. 실제 장소 5개 이상 검증 가능 여부 조사
3. scene/place 관계가 약하면 보류
4. 등장인물/작품 기본 데이터 구축
5. Work Detail + Map + Place 관계 생성
6. 상위 Tier만 퀴즈/문화콘텐츠 확장
7. KR 우선 공개, 언어별 ROI에 따라 확장

## 9. 디자인 작업과의 충돌 방지

디자인 Phase 1 및 Mobile UX Remediation과 병렬로 할 수 있는 것:
- 웹 리서치
- GSC 분석
- 콘텐츠 기획/리라이트 초안
- 관계 그래프 설계
- GitHub 문서/Issue

디자인 closeout 중 충돌 가능성이 있어 보류할 것:
- 공통 generator 대규모 수정
- 공통 CSS/헤더 수정
- 같은 작품 페이지 소스의 동시 대규모 변경

실제 코드 반영은 관련 디자인 PR이 main에 반영된 뒤 최신 main 기준으로 한다.
