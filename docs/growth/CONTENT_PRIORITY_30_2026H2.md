## 4. 왜 30개를 한꺼번에 제작하지 않는가

이 리스트는 **제작 큐가 아니라 투자 우선순위**다.

- 기존 A군은 실제 GSC 성과를 개선한다.
- 신규 B군은 촬영지 검증 통과자만 제작한다.
- 글로벌 C군은 현재 사이트의 K-content 중심 정체성을 해치지 않는 범위에서 확장한다.

실제 월간 제작량은 품질 유지 기준으로 3~6개가 적절하며, 기존 페이지 리라이트와 신규 제작을 혼합한다.

## 6. 재평가 규칙

2~4주마다 다음으로 순위를 다시 매긴다.
- GSC impression / clicks / CTR / position
- 신작 공개일/신시즌
- 실제 장소 검증 성과
- 내부링크 연결 가능 수
- 지도 진입/장소 클릭 행동 데이터
- 번역 준비 비용

목표는 '30개를 다 만드는 것'이 아니라 **검색성과와 장소탐색을 가장 빨리 키우는 3~6개를 계속 골라내는 것**이다.
