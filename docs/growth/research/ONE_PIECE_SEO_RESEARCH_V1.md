# One Piece SEO Research v1

Status: RESEARCH COMPLETE — implementation after collision check.

## Why this page matters

Search Console baseline (2026-08-25 export):
- page impressions: 98
- clicks: 4
- CTR: 4.1%
- average position: 13.81
- query `원피스 지역`: average position 8.69

The page has real search demand but currently mixes three different evidence classes: live-action filming, official ONE PIECE tourism, and fan-attributed visual inspirations.

## Current identity problem

Current title/H1:
`원피스 실제 모티브 장소 지도`

Current hero kicker:
`Netflix 실사판 · ONE PIECE · 실제 촬영지 & 숨은 이야기`

Current content then mixes:
1. Netflix live-action filming in Cape Town
2. official Kumamoto ONE PIECE statues
3. claimed manga/anime inspiration locations such as Venice/Rialto and Sagrada Família

These should not be presented as if they have the same evidentiary status.

## Recommendation summary

### P0 — separate evidence classes

Introduce three explicit labels throughout the page:
- `실사판 공식 촬영지`
- `공식 ONE PIECE 관련 장소`
- `비교/모티브 후보 — 공식 확인 없음`

A place that is visually similar or popular in fan discussions must not be described as an `actual motif` unless a primary source from Oda/Shueisha/official production confirms it.

### P0 — update stale 2026 production copy

Current copy says Season 3 is still filming in Cape Town.

Netflix Tudum states:
- Season 2 was filmed in Cape Town and premiered March 10, 2026.
- Season 3 began production in Cape Town in November 2025.
- Season 3 production **wrapped June 30, 2026**.

Update time-sensitive text accordingly.

### P0 — qualify Oda set-visit claims

Netflix officially confirms Eiichiro Oda visited the South Africa set for Season 2 and met returning/new cast.

Do **not** state that he personally inspected/approved every set and prop unless a primary source explicitly says so.

### P1 — title/meta direction

Because the strongest user intent is `원피스 지역`, the page should foreground real, visitable categories rather than an ambiguous motif claim.

Recommended title direction:
`원피스 실사 촬영지·실제 장소 지도 | 케이프타운·구마모토 | 그곳, 지금`

Recommended H1 direction:
`원피스 실사 촬영지와 실제로 갈 수 있는 장소`

Recommended meta direction:
`넷플릭스 원피스 실사판의 케이프타운 촬영지와 구마모토 ONE PIECE 부흥 프로젝트 동상 등 실제로 갈 수 있는 장소를 지도에서 확인하세요.`

Keep URL `/works/onepiece/`.

### P1 — reorganize page hierarchy

Recommended order:
1. Netflix live-action filming — Cape Town / South Africa
2. Official visitable ONE PIECE places — Kumamoto statues
3. Current season-production update
4. fan-comparison / motif candidates (only if clearly qualified)
5. map / related-region exploration

This is clearer than mixing studio sets, regions, tourist statues and fan motifs inside one TOP5 list.

### P1 — Kumamoto is a strong travel asset

Kumamoto City official tourism confirms:
- Luffy statue installed in 2018 as part of the ONE PIECE Kumamoto Revival Project
- project supports recovery from the April 2016 Kumamoto Earthquake
- Eiichiro Oda is a Kumamoto native
- Straw Hat statues are distributed around Kumamoto Prefecture

This section is trustworthy, visitable and highly aligned with the site's travel identity. Expand it rather than relying on weak motif speculation.

### P2 — internal discovery

Potential internal-link structure:
- One Piece → South Africa/Cape Town region
- One Piece → Kumamoto/Japan region
- Kumamoto statue places → other Japanese anime/place content
- Cape Town filming → other South Africa filming works when verified

Only link to routes/pages that actually exist.

## Decision

**SEO action: REFRAME.**

Do not simply add more locations. The page should become the authoritative distinction between:
`where Netflix actually filmed` vs `official ONE PIECE places you can visit` vs `fan-attributed inspiration candidates`.

That distinction itself can become a strong trust/SEO advantage.
