# Phase G Acceptance Summary v1

Phase G is accepted only when:
- place save/unsave works from required surfaces
- browser reload persists saves
- saved count/list is global
- saved identities survive KO/EN/JA/ZH switch without duplication
- saved list resolves fresh canonical localized data
- cross-work My Map works on existing MapLibre architecture, or developer stops with explicit `NEEDS DECISION` before a major rewrite
- no backend/auth/DB is introduced
- no existing SEO URL/canonical/hreflang/sitemap regression
- GA4 save/open events are verified
- 360/390/430 QA passes
- production is not deployed without user approval
