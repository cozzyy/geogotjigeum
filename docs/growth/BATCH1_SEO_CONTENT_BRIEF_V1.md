## 1. Breaking Bad

### Current
- title: `브레이킹 배드 앨버커키 촬영지 지도 | 그곳, 지금`
- description: `브레이킹 배드의 실제 촬영지와 배경이 된 앨버커키의 장소를 지도에서 확인하세요.`
- GSC: 135 impressions / 5 clicks / avg 10.13
- query: `앨버커키 브레이킹 배드` avg 8.90

### 판단
현재 title은 검색의도와 이미 잘 맞는다. 제목을 크게 흔들기보다 **snippet 구체성 + 앨버커키 장소 cluster + 내부링크**가 우선이다.

### Brief
- H2에 `앨버커키에서 실제로 볼 수 있는 브레이킹 배드 촬영지` 계열 질문형/자연어 섹션 검토
- 현재 데이터에 있는 대표 장소 3~5개를 description/초반부에 구체화
- 장소 page → 앨버커키/뉴멕시코 region → 같은 지역 다른 콘텐츠 연결
- `촬영지`와 단순 극중 배경 설정을 구분

## 2. One Piece

### Current

- description: `원피스 세계관에 영감을 준 실제 장소와 배경을 지도에서 확인하세요.`

매우 중요한 정확성 포인트: 애니/만화의 **실제 촬영지라고 쓰지 말고 모티브/영감 장소로 유지**한다.

### Brief
- `원피스 지역별 실제 모티브 장소` H2/탐색 구조 강화
- 국가/지역 단위로 모티브 장소를 묶어 사용자의 `지역` 의도에 답함
- 작품→모티브 장소→region→지도 관계 강화
- 실사 Netflix ONE PIECE 촬영지와 애니/만화 모티브를 섞지 않음. 별도 콘텐츠가 필요하면 별도 Work/section 판단

- 첫 화면에서 `촬영지 지도` CTA 명확화
- 핵심 place pages 및 지역 hub 역링크 보강
- 순위 하락 위험이 있으므로 수정 전/후 2주 비교 필수
