## 3. Current repo findings

The page currently contains 31 locations and detailed scene mapping. Overall quality is promising, but the label `직접` is too broad because it can represent:
- exact physical filming site
- whole city/region used as a production base
- location that visually represents another place

### A. Canadian scene precision
The official Netflix Canada map is a high-confidence canonical source for eight Canadian locations. Use those nodes first.

Do not confuse `Lake Louise` with the aurora scene: secondary reporting may mention Lake Louise elsewhere, but the official Netflix Canada location map identifies **Upper Kananaskis Lake** among the production locations. Scene-to-place mapping must be verified before claiming a specific scene was Lake Louise.

### B. Italy metadata is supported, but exact nodes should follow film commissions
`이탈리아 토스카나` in the current description is supported. Tuscany Film Commission specifically confirms Siena, Montalcino and Florence.

Other Italian places such as Rome/Perugia can be included only with their own strong local production sources rather than being inferred from the story.

### C. Japan is the page's best scene-first entrance
The current Kamakura/Enoshima cluster is highly specific and fits Episode 1 search/travel intent. Keep it as a walkable/public-transit cluster, but maintain source links for exact shop/street claims.

### D. Korea-as-overseas-double is a differentiator
Recent reporting shows that some scenes presented as overseas locations were actually filmed in Korea. This is exactly the kind of hidden-location twist that fits the site's editorial identity, but every double should be labelled `FILMED IN KOREA / STANDS IN FOR ...`, not simply `direct`.
