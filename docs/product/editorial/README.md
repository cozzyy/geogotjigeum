# 그곳지금 Editorial Workflow

개인 창작성은 작품별 운영자 인터뷰에서 나온다.

## Canonical process
1. 운영자 객관식 인터뷰(복수선택, 기억 안 남 허용)
2. Planner가 Editorial Thesis 작성
3. Fact Layer 별도 검증
4. 후킹페이지 전체를 인터뷰 관점에 맞춰 재편집
5. Scene 3개 / Core Place 3~5 / Hidden Fact 최대 3 선정
6. 개발자는 확정 copy/data만 구현

## 현재 완료
- `POKSSHAK_EDITORIAL_BRIEF_V1.md` — 인터뷰 완료, Fact audit 대기

개발자는 운영자의 의견을 임의로 추가하거나 기존 자동생성 copy를 Editorial로 간주하지 않는다.
