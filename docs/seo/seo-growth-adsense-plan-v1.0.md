# 그곳지금 SEO 성장 및 애드센스 운영 기획안 v1.0

**Search Console 초기 데이터 분석을 기반으로 한 4주 실행안**  
Google Search Console 데이터 기준: 2026-08-25 다운로드

## 핵심 판단

그곳지금은 검색 유입이 큰 단계는 아니지만 Google이 사이트의 주제와 개별 작품 페이지를 빠르게 인식하며 노출 범위를 넓히는 초기 성장 구간에 진입했다. 지금은 방문자 수보다 `노출 증가 → 10위권 진입 → 클릭 전환`의 흐름을 만드는 것이 우선이다.

## 1. Executive Summary

- 총 노출: **2,316**
- 총 클릭: **97**
- 검색어 수: **538**
- 최근 일평균 노출 증가: **약 6.6배**
- 초기 7일(8/5~8/11) 일평균 노출 34회 → 최근 8일(8/15~8/22) 227회
- 이미 여러 작품 페이지가 Google 평균 7~17위에 진입
- 단기 효율은 신규 콘텐츠 대량 추가보다 1페이지 경계권 페이지 집중 개선이 높음
- 우선순위: 한국어 → 일본어 → 선택적 영어권
- AdSense 승인 자체보다 검색 노출·클릭·체류·지도 탐색을 핵심 KPI로 둠

**권고 방향:** “콘텐츠를 더 많이 쌓는 단계”에서 “이미 노출되는 페이지를 10위권 안으로 밀고, 유입 사용자가 여러 장소를 탐색하도록 만드는 단계”로 전환.

## 4. SEO 실행 전략

### 4.1 콘텐츠 우선순위

A. 1페이지 경계권 개선: Breaking Bad, Harry Potter, Stranger Things, One Piece, 폭싹 속았수다, 오징어게임, 더 글로리 등  
B. 장소 중심 롱테일 확장: `앨버커키 브레이킹 배드`, `원피스 지역/지도`, `白夜行 舞台`  
C. 글쓰기 방식 유지: 20대 화자 + 장소 + 개인적 느낌 + 잘 알려지지 않은 이야기 1개 + 지도  
D. 내부링크 강화: 작품 → 주요 장소 → 같은 지역의 다른 작품 → 지도/여행코스  
E. 다국어 선택과 집중: 한국어 전반 강화, 일본어는 순위가 보이는 작품 우선, 영어는 경쟁 약한 장문 롱테일·질문형 중심

### 4.2 제목·메타 개선

- 제목은 `작품명 + 장소/촬영지 + 사용자가 궁금해할 한 가지`
- 메타 설명은 줄거리보다 장소·현재 방문 가능 여부·숨은 이야기·지도를 명확히 제시
- CTR 0%이면서 7~10위 키워드는 title/description/H1/H2 우선 점검
- 최근 수정일 표시, 재개봉·관광행사·촬영지 변화 시 업데이트

### 4.3 기술 SEO

- 한국어/영어/일본어 hreflang 상호 연결 및 canonical 검증
- 작품 페이지: Article + Breadcrumb, 목록: ItemList 검토
- 이미지 ALT 및 WebP/AVIF 최적화, LCP 이미지 우선 로딩
- 지도·광고 스크립트의 LCP/CLS/INP 영향 점검
- Search Console 색인 제외·크롤링 오류·사이트맵을 주 1회 확인

## 5. AdSense 운영 원칙

현 단계에서는 광고수익 최적화보다 서비스 사용성·SEO 성장 보존이 우선이다.

### 권장 배치

- 후킹 콘텐츠 중간 1개
- 본문 종료 후 지도/장소 탐색 CTA 직전 또는 직후 1개

### 당분간 피할 배치

- 메인 Hero
- 지도 오버레이·핀 클릭 패널·장소 카드 사이
- 전면 팝업·과도한 앵커 광고·스크롤 방해 광고

### 운영 체크

- 광고 전/후 LCP·CLS·INP 비교
- 지도 진입률·장소 클릭·체류시간이 감소하면 광고 수 즉시 축소
- 초기에는 Auto Ads 전면 허용보다 핵심 화면 제외 + 수동 배치 중심

## 6. 4주 실행 계획

| 기간 | 핵심 작업 | 실행 내용 | 대표 KPI |
|---|---|---|---|
| 1주차 | 데이터 정리·우선페이지 | 상위 10개 title/meta/H1/H2, 내부링크 | 10위권 검색어 수 |
| 2주차 | 콘텐츠 리라이트 | Breaking Bad·One Piece·폭싹·오징어게임·더 글로리 장소/숨은 이야기 보강 | CTR, 평균순위 |
| 3주차 | 장소형 SEO·일본어 테스트 | 앨버커키·원피스 지역/지도·白夜行 舞台 보강 | 롱테일 노출수 |
| 4주차 | UX·AdSense 검증 | 광고 1~2개, CWV·지도 행동 이벤트 비교 | 체류시간, 지도 진입률, 장소 클릭 |

## 7. KPI 및 판단 기준

| 지표 | 현재 상태 | 4주 판단 기준 |
|---|---|---|
| 검색 노출 | 최근 약 227회/일 | 500회/일 근접 여부 |
| 10위 이내 검색어 | 일부 롱테일 진입 | 주 단위 증가 여부 |
| 1페이지 경계 페이지 | 7~17위 다수 | 핵심 5개 중 2개 이상 10위 이내 |
| CTR | 검색 범위 확대 후 저하 | 7~10위권 키워드 CTR 개선 |
| 지도 행동 | 별도 추적 필요 | 지도 진입→핀 클릭→다음 장소 이벤트 수집 |
| AdSense | 승인 완료 | 수익보다 UX·CWV 영향 최소화 |

## 8. 최종 제안

Google은 이미 그곳지금을 알아보기 시작했다. 지금은 콘텐츠 수를 급격히 늘리는 것보다 이미 노출되는 페이지의 순위와 클릭률을 끌어올리고, 들어온 사용자가 장소를 연속 탐색하도록 만드는 것이 중요하다. AdSense는 이를 방해하지 않는 범위에서 최소 배치로 운영한다.
