# 그곳, 지금 글로벌 · SEO · UI · 콘텐츠 개선 개발기획안 V1

**개발자 인계용 V1 | Sonnet / Fable 업무 분리**  
2026.08 | AI 출판사 · 그곳, 지금

## 핵심 방향

그곳, 지금을 “작품 정보를 보는 사이트”에서 **작품을 현실의 장소와 여행으로 연결하는 글로벌 콘텐츠 플랫폼**으로 전환한다.

## 1. 기획 개요

이번 개편의 목표는 다음 4가지다.

- 첫 화면과 작품 탐색 흐름을 단순화해 이탈을 줄인다.
- 한국어·영어·일본어를 독립 URL로 운영해 글로벌 검색 유입을 만든다.
- 작품·배우·장소·지역을 서로 연결해 SEO 콘텐츠 네트워크를 만든다.
- 광고를 위한 억지 페이지뷰가 아니라 좋은 콘텐츠 때문에 자연스럽게 체류와 탐색이 늘어나는 구조로 전환한다.

### 대상 사용자

| 구분 | 핵심 목적 | 첫 화면 우선 콘텐츠 |
|---|---|---|
| 한국 사용자 | 좋아하는 작품의 실제 장소와 여행 | 인기작, 내 주변, 신규 작품 |
| 일본 사용자 | 한류 작품 기반 한국 성지순례 | 韓ドラロケ地, 聖地巡礼, 韓国旅行 |
| 미국·글로벌 | K-content 기반 Korea travel/글로벌 촬영지 | K-Drama Filming Locations, Seoul/Busan/Jeju |

## 2. 첫 방문 사용법 팝업 제거

**[SONNET / P0]** 첫 방문 자동 팝업을 제거한다. 상단 “사용법” 버튼과 안내 화면은 유지한다.

완료 기준: 첫 방문 시 서비스 화면이 바로 보이고 사용법 버튼을 클릭했을 때만 안내가 열린다.

## 3. 한·영·일 글로벌 사이트 구조

### 핵심 원칙

- 한국어 기존 URL은 유지한다.
- 영어 `/en/`, 일본어 `/ja/`를 독립 URL로 만든다.
- 모든 언어 페이지에 언어 전환 버튼을 상시 노출한다.
- 언어 전환 시 홈이 아니라 동일 작품·동일 장소의 해당 언어 페이지로 이동한다.

### 권장 URL

```text
/works/pokshak/        # 한국어
/en/works/pokshak/     # 영어
/ja/works/pokshak/     # 일본어
/                      # 한국어 홈
/en/                   # 영어 홈
/ja/                   # 일본어 홈
```

**[FABLE / P0]** 다국어 URL·라우팅·데이터 아키텍처를 구현한다. 작품·장소·배우·등장인물·여행코스 데이터에 ko/en/ja 필드를 도입하고 동일 엔티티 간 URL 매핑을 유지한다.

**[SONNET / P1]** 언어 선택 UI를 구현한다.

## 4. 접속 국가·브라우저 기반 초기 언어

권장 우선순위:

1. 사용자가 과거 직접 선택한 언어
2. 브라우저 언어
3. 접속 국가
4. 기본값 영어

강제 리디렉션은 최소화하고 검색 유입 URL에서는 언어를 강제로 바꾸지 않는다.

## 5. 번역 범위

버튼만 번역하지 않고 페이지 전체를 언어별 완결 콘텐츠로 만든다.

- 메뉴 / 버튼 / 작품 제목 / 작품 설명
- 장소명 / 장소 설명 / 여행 정보 / 투어 설명
- 등장인물 / 실제 배우 / 배우 설명
- 검색어 / 태그 / 이미지 ALT
- title / meta description / OG title / OG description
- JSON-LD 텍스트

예시:

```js
title: {
  ko: "폭싹 속았수다",
  en: "When Life Gives You Tangerines",
  ja: "おつかれさま"
}
```

## 6. 한국·일본·미국 SEO 전략

### 한국 SEO

- 작품명 + 촬영지
- 작품명 + 장소 / 배경 / 여행 / 등장인물
- 배우명 + 촬영지
- 지역 + 드라마 촬영지

### 일본 SEO

- ロケ地
- 撮影地
- 聖地巡礼
- 舞台
- 韓ドラ
- 韓国旅行
- アクセス
- ロケ地マップ

### 영어·미국 SEO

- filming locations / shooting locations
- where was [title] filmed
- K-drama filming locations
- Korea filming locations
- travel map / itinerary / cast / characters

**[FABLE / P0]** canonical, hreflang, sitemap, 언어별 title/description/H1/OG를 독립 생성하고 정적/SSR HTML에 실제 텍스트를 포함한다.

## 7. 지역별 SEO 콘텐츠 허브

주요 지역을 독립 검색 진입점으로 만든다.

```text
/seoul/
/busan/
/jeju/
/gyeongju/
/suwon/
/en/korea/seoul/
/en/korea/busan/
/en/korea/jeju/
/ja/korea/seoul/
/ja/korea/busan/
```

지역 페이지는 작품·장소·투어·배우를 내부링크로 연결하고 독자 소개문·대표 이미지·추천 코스를 제공한다.

## 8. 등장인물 + 실제 배우

캐릭터와 실제 배우를 분리해서 보여준다.

- 캐릭터명과 배우명 분리 표시
- 배우 사진 카드
- 배우 클릭 시 관련 작품·장소 연결
- actor_id / ko-en-ja 이름 / profile / works / places 관계 설계
- 배우명 통합검색 지원

## 9. 사진·영상 콘텐츠 강화

### 사진 소스 원칙

허용:

- 직접 촬영
- 사용자 업로드 + 노출 동의
- Wikimedia Commons 등 상업적 재사용 가능 이미지
- 상업적 재사용이 허용된 공공 이미지
- 정식 라이선스 이미지

금지:

- Google·네이버 이미지 단순 복사
- OTT 화면 캡처
- IMDb 등 타 서비스 배우 사진 무단 다운로드
- 라이선스 불명확 포스터·스틸

**[FABLE / P1]** `media_id / entity_type / image_url / source_url / author / license / license_url / commercial_use / attribution / verified_at` 등 미디어 라이선스 DB를 관리한다.

### 공식 영상

공식 YouTube 영상만 임베드하고 다운로드·재업로드하지 않는다.

## 10. 작품 선택 흐름 개선

작품 카드에 두 진입 버튼을 제공한다.

- `작품 보기` → 작품 허브
- `지도 바로가기` → 지도형 상세

작품 허브 권장 구조:

1. 대표 이미지
2. 30초 작품 소개
3. 등장인물 + 실제 배우
4. 공식 예고편
5. 대표 촬영지 TOP 5
6. 광고
7. 전체 지도 보기
8. 추천 여행코스
9. 관련 작품

핵심 원칙: 광고를 보기 위한 중간페이지가 아니라 자체 검색 유입과 체류가 가능한 콘텐츠 페이지로 만든다.

## 11. 초기화면 개편

첫 화면에서는 긴 설명보다 다음을 먼저 보여준다.

- 작품·장소·배우 검색
- 지금 인기 있는 작품
- 내 주변에서 찾기
- 한국 한류 여행

언어별 홈 큐레이션도 별도로 운영한다.

## 12. 통합검색

검색 대상을 작품·장소·등장인물·배우·여행코스로 확장한다.

예: `파친코 / 김태리 / 제주 / 경복궁 / 아이유 / 스파이더맨 / 부산`

**[FABLE / P1]** work/place/character/actor/itinerary 통합 검색 인덱스를 구성한다.

## 13. 장소 ↔ 작품 ↔ 배우 관계형 콘텐츠

같은 장소, 배우, 시대, 지역 기준으로 관련 콘텐츠를 자동 연결한다.

예:

```text
경복궁
 ├ 작품 A
 ├ 작품 B
 ├ 작품 C
 └ 경복궁에서 촬영된 드라마 12편
```

## 14. 이미지 SEO·OG·구조화 데이터

**[SONNET / P2]** 이미지 ALT와 작품별 고유 og:image를 자동화하고 대표 이미지가 없으면 텍스트 기반 OG 카드를 생성한다.

**[FABLE / P2]** BreadcrumbList, Movie/TVSeries, Person, VideoObject 등 구조화 데이터를 검토한다.

## 16. 여행 기능 확장

지역: 서울·부산·제주·경주·전주·수원

작품별 1일 코스 예:

```text
09:00 장소 A
11:00 장소 B
13:00 식당
15:00 장소 C
18:00 장소 D
```

장소 신뢰도:

- ✓ 촬영 확인
- △ 유력
- ? 미확인

장기적으로 숙박·투어·교통·티켓 제휴까지 연결 가능하게 설계한다.

## 17. 작품 속 모습 / 지금 모습

권리 확보된 이미지가 있을 때만 작품 스틸을 사용한다. 미확보 시 작품 장면 설명 + 현재 장소 사진으로 구성한다.

## 18. 광고 수익 구조 원칙

광고는 “클릭을 한 번 더 시키는 장치”가 아니라 좋은 콘텐츠 사이에 자연스럽게 배치되는 수익화 요소로 본다.

- 작품 허브 자체의 콘텐츠 가치 강화
- 지도 바로가기와 작품 보기 분리
- 광고는 작품 소개·배우·대표 장소·전체 지도 사이에 배치
- 버튼과 광고가 혼동되지 않게 함

## 21. 개발 완료 공통 QA 체크리스트

- [ ] 한국어 기존 URL에 새 301/404 문제 없음
- [ ] ko/en/ja 페이지 직접 접근 가능
- [ ] 언어 버튼이 동일 엔티티 다른 언어로 이동
- [ ] title/description/H1/canonical/hreflang 정상
- [ ] sitemap에 신규 언어 URL 포함
- [ ] robots.txt가 신규 경로를 막지 않음
- [ ] 배우·장소·작품 내부 링크가 실제 `<a href>`로 존재
- [ ] 이미지 ALT 누락 없음
- [ ] 미디어 라이선스 미확인 이미지는 미노출
- [ ] 모바일에서 검색·언어변경·작품보기·지도 버튼 겹침 없음
- [ ] 자동 사용법 팝업 제거
- [ ] AdSense 코드와 ads.txt 유지
