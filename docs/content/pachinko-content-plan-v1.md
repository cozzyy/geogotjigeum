# Apple TV+ 『파친코』 신규 콘텐츠 기획안 V1

**그곳지금 콘텐츠 플랫폼 실무 설계 · GitHub 이관용 구조화본**  
원본 작성일: 2026-08-05

## 1. 콘텐츠 포지셔닝

『파친코』를 단순 촬영지 목록이 아니라 **부산 영도 → 오사카 → 도쿄 → 미국으로 이어지는 4세대 가족사, 역사, 이주와 장소를 연결하는 장기 운영형 콘텐츠**로 구성한다.

작품은 Netflix가 아니라 **Apple TV+ 오리지널 시리즈**로 등록한다. 당시 확인 기준 공식 공개 범위는 시즌 1·2, 총 16회이며 후속 시즌은 공식 발표 확인 후 업데이트한다.

## 2. 원안 규모

- 긴 줄거리: 41개 서사 단락
- 인물/배역 데이터 노드: 118개
- 장소 데이터 노드: 138개
- 검색·해시태그: 366개

## 3. 정확성 원칙

- 작품에 존재하지 않는 고유 이름을 만들어 인물 수를 채우지 않는다.
- 동일 인물의 연령·시기별 배역, 공식 크레딧의 기능 배역, 관계도용 집단 노드를 구분한다.
- 장소는 아래 유형을 서로 다른 배지로 구분한다.
  - 이야기 공간
  - 실제 촬영 확인 장소
  - 재현 세트
  - 역사 연계 장소
  - 테마 추천 장소
- 촬영 여부가 불확실한 곳은 실제 촬영지로 단정하지 않는다.

## 4. 홈페이지 등록 방향

- 작품명: `파친코 / Pachinko`
- 플랫폼: Apple TV+
- 콘텐츠 유형: 드라마 · 역사 · 가족 · 디아스포라 · 문학 원작
- 핵심 지역: 부산 영도, 오사카, 도쿄, 미국
- 핵심 사용자 행동: 작품 이해 → 인물 관계 → 장소 탐색 → 역사 이해 → 여행 코스

## 6. 장소 데이터 구조 권고

각 장소에 다음 값을 붙인다.

```text
place_id
name_ko / name_en / name_ja
country / region / city
lat / lng
relation_type
filming_status
scene_or_story_relation
source
verified_at
visitability
map_url
```

`relation_type`은 `FILMING / STORY / SET / HISTORY / RECOMMENDATION`처럼 명시적으로 구분한다.
