# Stock Forecasting

그곳지금(geogotjigeum)의 하위 서비스로 개발하는 주가 예측 프로젝트.

## 목적

- 사용자가 선택한 종목의 단기 주가 흐름을 데이터 기반으로 예측
- 단일 가격값보다 확률·범위·방향성을 함께 제공
- 예측 결과와 근거 신호를 이해하기 쉽게 시각화
- 그곳지금 주식 콘텐츠와 자연스럽게 연결

## 역할

- 사용자: 서비스 방향과 주요 의사결정
- ChatGPT: 서비스 기획, 예측 알고리즘 공동 설계, 변수 탐색, 백테스트 설계, 개발 명세 작성
- Claude: 데이터 파이프라인, 모델, API, UI 등 실제 코드 구현
- GitHub: 기획·알고리즘·구현·실험 결과 공유

## 디렉토리

- docs/ : 기획 및 알고리즘 명세
- experiments/ : 백테스트 및 모델 실험
- src/ : 서비스 코드
- models/ : 채택 모델 및 설정
- tests/ : 테스트
- data/ : 데이터 스키마 및 로컬 개발용 샘플(대용량 원본 데이터는 직접 커밋하지 않음)

## 현재 단계

1. 예측 타깃 정의
2. 후보 feature 정의
3. baseline 모델 설계
4. walk-forward backtest
5. 모델 비교 및 채택
6. API/UI 연결
