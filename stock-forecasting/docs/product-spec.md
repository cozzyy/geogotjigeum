# Product Spec

## 서비스 위치

그곳지금 주식 관련 콘텐츠의 하위 기능으로 제공하는 주가 예측 서비스.

## 핵심 사용자 경험

1. 종목 선택
2. 예측 기간 선택
3. 예측 결과 확인
4. 상승/하락 확률, 예상 가격 범위, 주요 근거 신호 확인
5. 과거 동일 조건에서의 적중률 확인

## 원칙

- 재미와 탐색 중심의 서비스
- 확정적 표현보다 확률과 범위 중심
- 모델 성능과 한계를 함께 표시
- 과거 검증 결과를 사용자에게 숨기지 않음
- 특정 투자행동을 직접 권고하지 않음

## 미확정 사항

- 예측 타깃: 1일 / 5일 / 20일
- 결과 형식: 방향 / 확률 / 가격범위 / 예상수익률
- 지원 종목 범위
- 실시간 데이터 공급원
