# Inbox — 미정리 입력 보관소

`inbox/`는 아직 정식 작업으로 확정되지 않은 아이디어, 녹취, 이메일 요약, 회의 메모, 링크 등을 임시로 보관하는 곳이다.

## 원칙
- 원문의 의미를 훼손하지 않는다.
- 정리되지 않은 상태 그대로 들어와도 된다.
- 에이전트는 기존 문서/Issue와 중복 여부를 확인한다.
- 실행 가치가 있으면 GitHub Issue로 전환한다.
- Issue로 전환된 뒤에도 원문 보존 가치가 있으면 이 폴더에 남긴다.

## 권장 하위 폴더
- `ideas/` 아이디어
- `transcripts/` 녹취록
- `emails/` 이메일에서 유입된 업무
- `notes/` 메모·회의 메모

Git은 빈 폴더를 관리하지 않으므로 필요한 시점에 파일과 함께 하위 폴더를 생성한다.

## 파일명 예시
`2026-08-26-jeju-one-day-route-idea.md`

## 정리 형식
```md
# 제목

- 입력일:
- Source: Voice Memo / Email / Meeting / User / Other
- 관련 작품/기능:

## 원문 또는 요약

## AI 정리
- 핵심 아이디어:
- 기존 작업과 중복 여부:
- 추천 Type:
- 추천 Priority:
- 추천 Area:
- 다음 행동:

## 연결된 Issue
- #번호 또는 없음
```
