# 그곳지금 콘텐츠 제작 스킬 v1.0

## 1. 언제 사용하나
다음 작업에서는 이 스킬을 반드시 적용한다.
- 신규 영화/드라마/예능/애니메이션/OTT 작품 등록
- 기존 작품 콘텐츠 대규모 확장
- 작품별 등장인물/장소/해시태그 데이터 구축
- 후킹 페이지, 촬영지, 여행코스, 숨은 이야기, 퀴즈의 통합 기획
- 신규 콘텐츠 개발을 Claude에게 넘기기 위한 기획안 작성

단순 오탈자 수정, 짧은 카피 1~2줄 수정에는 강제하지 않는다.

## 2. 핵심 철학
그곳지금의 작품 콘텐츠는 단순한 줄거리 요약이나 촬영지 목록이 아니다.

**작품 → 인물 → 장면 → 실제 장소 → 숨은 이야기 → 여행 → 지도 → 검색**이 서로 연결되는 데이터형 콘텐츠를 만든다.

양은 충분히 크게 만들되, 숫자를 채우기 위해 사실을 만들어내지 않는다.

## 3. 최소 목표 규모
신규 주요 작품은 아래 규모를 기본 목표로 한다.

### 등장인물
- 목표: **100명 이상**
- 주연, 조연, 단역, 가족, 조직, 관계 인물, 공식 크레딧 인물을 폭넓게 조사한다.
- 동일 인물의 아역/성인역 등은 필요 시 별도 배역 노드로 관리하되 동일 인물임을 명확히 표시한다.
- 이름 없는 기능 배역은 공식 크레딧 또는 신뢰 가능한 근거가 있을 때만 포함한다.

### 장소
- 목표: **100개 이상**
- 단순 촬영지만 100개를 억지로 찾지 않는다.
- 아래 유형을 구분하여 확장한다.
  - `FILMING`: 실제 촬영 확인 장소
  - `STORY`: 작품 속 이야기 배경
  - `SET`: 세트/재현 공간
  - `HISTORY`: 작품 이해에 중요한 역사·문화 연계 장소
  - `RECOMMENDATION`: 작품 테마와 연결되는 여행 추천 장소
- 실제 촬영 여부가 불확실한 곳은 `FILMING`으로 표시하지 않는다.

### 해시태그/검색 키워드
- 작품명, 원제, 배우, 등장인물, 지역, 장소, 장면, 시대, 감정, 장르, 여행, 촬영지, 밈, 글로벌 검색어를 폭넓게 구축한다.
- 단순 반복어를 제외하고 **충분히 풍부한 키워드 풀**을 만든다.
- KR / EN / JP / ZH 검색 확장을 고려한다.

### 본문 분량
- 작품 소개 몇 문단으로 끝내지 않는다.
- 줄거리, 인물관계, 대표 장면, 장소, 제작 비하인드, 지역 이야기, 여행 포인트가 각각 독립적으로 읽힐 정도의 깊이를 확보한다.

## 4. 숫자 하한선과 정확성 충돌 시 처리
`100명 이상`, `100개 이상`은 **목표 하한선**이지 허위 데이터 생성 명령이 아니다.

검증 가능한 데이터가 목표보다 적으면:
1. 추가 소스를 더 조사한다.
2. 관계 인물/역사·테마 장소 등 정당한 확장 범위를 검토한다.
3. 그래도 부족하면 검증 가능한 최대치까지만 작성한다.
4. 기획안에 `목표 미달`, 실제 확보 수, 부족 사유를 명확히 기록한다.

금지:
- 존재하지 않는 인물 생성
- 확인되지 않은 장소를 촬영지로 단정
- 같은 장소/인물을 이름만 바꿔 중복 카운트
- SEO 숫자를 늘리기 위한 무의미한 태그 반복

## 5. 작품별 필수 콘텐츠 구성
가능하면 아래 섹션을 모두 설계한다.

1. 10~30초 후킹 카피
2. 작품 기본정보
3. 스포일러 안전 작품 소개
4. 충분한 줄거리/세계관
5. 인물 관계 및 등장인물 데이터
6. 대표 장면
7. 대표 장소 TOP 5~10
8. 전체 장소 데이터
9. 실제 촬영지 vs 극중 배경 구분
10. 지도 탐색
11. 지역별/테마별 여행코스
12. 주변 연계 장소
13. 제작 비하인드
14. 잘 알려지지 않은 숨은 이야기
15. 의외성/반전성 정보 최소 1개
16. 퀴즈/참여 요소
17. 관련 작품/배우/지역 연결
18. SEO 제목/설명/롱테일 키워드
19. 다국어 확장 기준
20. 출처와 검증일

## 6. 후킹 페이지 톤
일반 사용자용 글은 회사 보고서처럼 쓰지 않는다.

기본 독자: 20~30대

원칙:
- 친구가 얘기해주는 듯한 자연스러운 말투
- 짧은 문장과 리듬
- 개인적 반응이나 함께 발견하는 느낌 허용
- 과도한 정보 나열 지양
- AI가 쓴 듯 지나치게 매끈한 문장 지양
- 첫 부분에서 장소나 이야기의 반전을 보여줄 것
- 가르치거나 훈계하는 말투 금지

단, 데이터 필드·관리문서는 정확하고 구조적인 문체를 사용한다.

## 7. 숨은 이야기 기준
각 주요 작품에는 최소 1개의 강한 숨은 이야기/반전 포인트를 확보한다.

우선순위:
1. 촬영 장소가 화면에서 하나처럼 보이지만 실제 여러 장소를 합성/조합한 사례
2. 장소의 실제 역사와 작품 장면의 의외의 연결
3. 배우/제작진의 촬영 비하인드
4. 세트와 실제 장소의 차이
5. 삭제 장면/로케이션 변경/촬영 난관
6. 현지 주민·관광 변화 등 작품 공개 후의 실제 변화

흔한 위키 수준 정보보다 한 단계 깊은 자료를 찾는다.

## 10. 해시태그 분류
해시태그/검색어는 무작위 한 덩어리로 만들지 않고 아래 축으로 분류한다.

- 작품명/원제/플랫폼
- 배우/등장인물
- 지역/도시/장소
- 촬영지
- 장면/대사/사건
- 장르/감정
- 역사/문화
- 여행 의도
- 계절/데이트/혼행/가족여행 등 이용상황
- 한국어 SEO
- 영어 SEO
- 일본어 SEO
- 중국어 SEO

## 11. SEO 기본 산출물
작품마다 가능한 경우 다음을 만든다.
- SEO title
- Meta description
- 대표 H1
- 한국어 핵심 검색어
- 영어 핵심 검색어
- 일본어 핵심 검색어
- 중국어 핵심 검색어
- 롱테일 키워드
- 지역+작품 조합 키워드
- 배우+장소 조합 키워드
- 내부링크 후보

## 12. 여행 확장
그곳지금의 차별점은 작품 설명에서 여행 행동으로 넘어가는 데 있다.

각 작품에서 검토:
- 반나절 코스
- 1일 코스
- 지역별 코스
- 대중교통 중심 코스
- 도보 클러스터
- 주변 맛집/관광지는 별도 검증 후 연결
- 같은 지역의 다른 작품 촬영지 연결
- 현재 위치 기반 주변 촬영지로 확장 가능성

## 13. 다국어
기본 지원 언어는 프로젝트 `PROJECT_STATE.md`의 최신 정책을 따른다.

원칙:
- 단순 직역 금지
- 작품명·인명·지명은 해당 언어권 공식 표기 우선
- 해당 언어 콘텐츠가 실제로 준비되지 않은 경우 다른 언어 페이지로 조용히 보내지 않는다.
- 다국어 작업 전 언어 availability 규칙을 확인한다.

## 14. 조사 우선순위
최신·검증 가능한 자료를 우선한다.

1. 공식 플랫폼/제작사/방송사
2. 지자체·관광공사·공공기관의 촬영지 자료
3. 제작진·배우 공식 인터뷰
4. 신뢰도 높은 언론
5. 로케이션 관련 공식/현지 자료
6. 블로그·유튜브·커뮤니티는 숨은 이야기 후보 발굴에 활용하되 교차검증

촬영지 사실은 블로그 하나만으로 단정하지 않는다.

## 15. 신규 콘텐츠 기획 결과물 최소 항목
ChatGPT가 Claude에게 넘길 기획안에는 최소 다음을 포함한다.

- 작품 선정 이유
- 최신성/인기도 근거
- 콘텐츠 핵심 훅
- 작품 기본정보
- 예상 등장인물 데이터 규모
- 예상 장소 데이터 규모
- 주요 장소 후보
- 숨은 이야기/반전 포인트
- 페이지 구조
- 해시태그/SEO 전략
- 여행 확장
- 다국어 전략
- 필요한 데이터/개발 작업
- 완료 기준
- 검증이 더 필요한 항목

## 16. Claude 개발 인수인계
기획이 개발로 이어지는 경우 반드시 `docs/CHATGPT_CLAUDE_HANDOFF.md`를 함께 따른다.

ChatGPT는:
- 기획안을 `docs/content/`에 저장
- Handoff Issue 생성
- 개발 승인 상태를 임의로 승인하지 않음

Claude는:
- 이 스킬과 기획안을 읽은 뒤 기술 검토
- `READY FOR APPROVAL / NEEDS DECISION / BLOCKED` 중 하나로 보고
- 사용자 승인 전 코드 구현 금지

## 17. 품질 게이트
콘텐츠를 완료로 보기 전에 `QUALITY_CHECKLIST.md`를 사용해 점검한다.

특히 다음 중 하나라도 문제가 있으면 Done 처리하지 않는다.
- 가짜/추정 인물을 사실처럼 작성
- 촬영지 근거 미확인
- 장소 유형 미구분
- 숨은 이야기 부재
- 검색/해시태그 빈약
- 여행 연결 부재
- 출처/검증일 부재
- 기획안과 구현 결과가 크게 불일치
