# 그곳지금 콘텐츠 품질 체크리스트 v1.0

신규 작품 콘텐츠 또는 대규모 콘텐츠 확장 작업을 Done 처리하기 전에 사용한다.

## A. 규모
- [ ] 등장인물 100명 이상을 목표로 충분히 조사했는가?
- [ ] 실제 검증 가능한 인물 수가 100명 미만이면 확보 수와 부족 사유를 적었는가?
- [ ] 장소 100개 이상을 목표로 FILMING/STORY/SET/HISTORY/RECOMMENDATION까지 합리적으로 확장했는가?
- [ ] 실제 검증 가능한 장소 수가 100개 미만이면 확보 수와 부족 사유를 적었는가?
- [ ] 해시태그/검색 키워드가 작품명 반복 수준을 넘어서 충분히 풍부한가?
- [ ] 본문이 짧은 줄거리 요약에 그치지 않고 인물·장면·장소·여행·비하인드까지 충분히 깊은가?

## B. 정확성
- [ ] 존재하지 않는 인물이나 장소를 만들지 않았는가?
- [ ] 동일 인물/장소의 중복 카운트를 피했는가?
- [ ] 실제 촬영지와 극중 배경을 구분했는가?
- [ ] 촬영지 근거를 확인했는가?
- [ ] 최신 정보는 확인일을 남겼는가?
- [ ] 추정 정보는 추정임을 표시했는가?

## C. 사용자 재미
- [ ] 첫 화면에 강한 후킹 포인트가 있는가?
- [ ] 잘 알려지지 않은 숨은 이야기 또는 반전 정보가 최소 1개 이상 있는가?
- [ ] 일반 사용자 문체가 20~30대 친구 말투에 가깝고 설명서처럼 딱딱하지 않은가?
- [ ] 정보만 나열하지 않고 장면과 장소를 이야기로 연결했는가?

## D. 장소/여행
- [ ] 대표 장소 TOP 5~10이 선정되어 있는가?
- [ ] 지도 탐색이 가능한 구조인가?
- [ ] 최소 1개 이상의 여행코스 확장 아이디어가 있는가?
- [ ] 같은 지역의 다른 작품/장소로 내부 연결할 수 있는가?
- [ ] 방문 가능 여부와 현재 상태를 확인했는가?

## E. 검색/확장
- [ ] SEO title / Meta description이 있는가?
- [ ] 한국어 롱테일 키워드가 있는가?
- [ ] 영어 검색 확장을 고려했는가?
- [ ] 일본어 검색 확장을 고려했는가?
- [ ] 중국어 검색 확장을 고려했는가?
- [ ] 배우+지역 / 작품+지역 / 장면+장소 조합 키워드가 있는가?

## F. 개발 인수인계
- [ ] 기획문서가 `docs/content/`에 저장되어 있는가?
- [ ] 개발이 필요하면 Handoff Issue가 생성되어 있는가?
- [ ] 개발 범위와 제외 범위가 명확한가?
- [ ] 완료 기준이 체크박스로 정의되어 있는가?
- [ ] 사용자 승인 전 Claude가 구현하지 않도록 상태가 명확한가?

## 최종 판정
- **PASS**: 핵심 항목을 충족하고 사실성 문제가 없음
- **PASS WITH GAPS**: 목표 규모 일부 미달이나 사유·근거가 명확함
- **FAIL**: 허위/추정 데이터, 촬영지 오분류, 출처 부족, 콘텐츠 깊이 부족 등 핵심 문제 존재
