# 그곳지금 콘텐츠 품질 체크리스트 v1.1

신규 작품 콘텐츠 또는 대규모 콘텐츠 확장 작업을 Done 처리하기 전에 사용한다.

## A. 규모
- [ ] 등장인물 100명 이상을 목표로 충분히 조사했는가?
- [ ] 실제 검증 가능한 인물 수가 100명 미만이면 확보 수와 부족 사유를 적었는가?
- [ ] 장소 100개 이상을 목표로 FILMING/STORY/SET/HISTORY/RECOMMENDATION까지 합리적으로 확장했는가?
- [ ] 실제 검증 가능한 장소 수가 100개 미만이면 확보 수와 부족 사유를 적었는가?
- [ ] 해시태그/검색 키워드가 작품명 반복 수준을 넘어서 충분히 풍부한가?
- [ ] 본문이 짧은 줄거리 요약에 그치지 않고 인물·장면·장소·여행·비하인드까지 충분히 깊은가?

## B. 정확성
- [ ] 존재하지 않는 인물이나 장소를 만들지 않았는가?
- [ ] 동일 인물/장소의 중복 카운트를 피했는가?
- [ ] 실제 촬영지와 극중 배경을 구분했는가?
- [ ] 촬영지 근거를 확인했는가?
- [ ] 최신 정보는 확인일을 남겼는가?
- [ ] 추정 정보는 추정임을 표시했는가?

## C. 창의성·차별화
- [ ] 기존 그곳지금 최근 콘텐츠 3개 이상과 제목/첫 문장/구조를 비교했는가?
- [ ] `사실은 ~였다`, `알고 보니 ~`, `한 곳이 아니었다` 같은 훅 공식을 반복하지 않았는가?
- [ ] 서로 다른 콘텐츠 콘셉트 후보를 3개 이상 만든 뒤 최종안을 골랐는가?
- [ ] 작품 자체의 특징에 맞게 페이지 순서와 리듬을 새로 설계했는가?
- [ ] 다른 작품에서도 쓴 동일한 후킹 구조를 습관적으로 재사용하지 않았는가?

## D. 경쟁조사
- [ ] 공식 플랫폼/제작사/방송사 자료를 확인했는가?
- [ ] 국내외 경쟁/유관 사이트를 충분히 비교했는가?
- [ ] 영향력 있는 관련 YouTube 영상을 3개 이상 검토했는가? 자료가 부족하면 사유를 남겼는가?
- [ ] 댓글/커뮤니티에서 반복되는 질문이나 오해를 확인했는가?
- [ ] `이미 흔한 것 / 비어 있는 것 / 그곳지금만의 각도`를 정리했는가?
- [ ] 경쟁 콘텐츠를 복제하지 않고 새로운 구성으로 재설계했는가?

## E. 사용자 재미
- [ ] 첫 화면에 클릭할 이유가 명확한가?
- [ ] 잘 알려지지 않은 숨은 이야기 또는 발견 포인트가 있는가?
- [ ] 일반 사용자 문체가 20~30대 친구 말투에 가깝고 설명서처럼 딱딱하지 않은가?
- [ ] 정보만 나열하지 않고 장면과 장소를 이야기로 연결했는가?

## F. 모바일 화면
- [ ] 360 / 390 / 430px 기준으로 첫 화면을 검토했는가?
- [ ] 핵심 제목·정보·CTA가 첫 1~2스크린 안에서 이해되는가?
- [ ] 버튼·탭·카드의 터치 영역이 충분한가?
- [ ] 긴 작품명·인물명·지명·해시태그가 깨지거나 넘치지 않는가?
- [ ] 100명/100장소 데이터에 검색·필터·접기·탭 등 탐색 장치가 있는가?
- [ ] 지도와 콘텐츠 전환이 모바일에서 단순한가?
- [ ] 이미지와 자막이 화면을 과도하게 점유하지 않는가?
- [ ] 고정 메뉴/하단 CTA가 본문을 가리지 않는가?
- [ ] 퀴즈 4개 선택지와 다음 버튼을 엄지손가락으로 편하게 누를 수 있는가?
- [ ] 이미지 용량·로딩·CLS 등 체감 성능을 고려했는가?

## G. 장소/여행
- [ ] 대표 장소 TOP 5~10이 선정되어 있는가?
- [ ] 지도 탐색이 가능한 구조인가?
- [ ] 최소 1개 이상의 여행코스 확장 아이디어가 있는가?
- [ ] 같은 지역의 다른 작품/장소로 내부 연결할 수 있는가?
- [ ] 방문 가능 여부와 현재 상태를 확인했는가?

## H. 퀴즈 20문제
- [ ] 작품 전용 Quiz 메뉴/독립 URL을 설계했는가?
- [ ] 정확히 20문제를 준비했는가?
- [ ] 모든 문항이 4지선다이며 정답이 하나뿐인가?
- [ ] 작품 기억/인물·사건 약 5문제가 있는가?
- [ ] 장소·촬영지 약 8문제가 있는가?
- [ ] 숨은 이야기·비하인드 약 4문제가 있는가?
- [ ] 팬용 세부 문제 약 3문제가 있는가?
- [ ] 장소 연계 문제 8~10개에 장소/지도 링크를 연결할 수 있는가?
- [ ] 정답/오답 뒤 짧은 해설이 있는가?
- [ ] 퀴즈가 단순 암기 20문제로 끝나지 않는가?
- [ ] 모바일에서 문항과 선택지 길이가 적절한가?
- [ ] `docs/product/quiz-expansion-plan-v1.1.md`와 기존 폭싹 퀴즈 패턴을 참고했는가?

## J. 개발 인수인계

## K. 스킬 지속개선
- [ ] 이번 작업에서 다른 작품에도 반복될 규칙/문제가 새로 발견됐는가?
- [ ] 발견됐다면 `SKILL.md`, 관련 체크리스트/템플릿에 반영할 필요를 검토했는가?
- [ ] 스킬을 수정했다면 `CHANGELOG.md`에 기록했는가?

## 최종 판정
- **PASS**: 핵심 항목을 충족하고 사실성·모바일·퀴즈·차별화에 문제가 없음
- **PASS WITH GAPS**: 목표 규모나 외부 자료 일부 부족하지만 사유·근거가 명확함
- **FAIL**: 허위/추정 데이터, 촬영지 오분류, 경쟁조사 부재, 반복 기획, 모바일 미검토, 퀴즈 미구성, 출처 부족, 콘텐츠 깊이 부족 등 핵심 문제 존재
